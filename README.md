## Sobre mí

Soy desarrollador web full-stack con formación especializada en ciberseguridad. Combino el desarrollo de aplicaciones (Spring Boot, Angular, Laravel) con prácticas de **Security by Design**: la seguridad forma parte del diseño, el código, el pipeline y la infraestructura, no una revisión al final.

Áreas en las que trabajo y quiero crecer:

- **Seguridad de aplicaciones web y APIs** — controles basados en OWASP Top 10 y OWASP API Security Top 10.
- **DevSecOps** — análisis SAST, SCA y de contenedores integrados en CI/CD.
- **Hardening e infraestructura** — bastionado de Linux, contenedores Docker y reverse proxy con TLS.
- **Detección y respuesta** — monitorización, análisis de tráfico y forense básico.
